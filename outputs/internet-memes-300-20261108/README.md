# インターネットミーム300問

2026年11月8日作成。[取り込み用CSV](internet-memes-300.csv)に300問を収録。

日本の掲示板・AA・音MAD、海外の画像・動画・楽曲、ゲームや映画の台詞、動物、ネット怪談などを扱う。ミームの名前に加え、元作品、制作・撮影の経緯、人物、派生表現も出題する。段階的な手がかりと短い知識問題を混ぜ、同じ題材の問題は隣接しにくい順序にしている。

アプリの「問題を管理」→「CSV取り込み」で選択する。問題集名は「インターネットミーム300問（2026年11月作成）」、大ジャンルは「インターネットカルチャー」。

各問に正解、必要な別解、出典URL、短い解説、出典確認日を設定。読み上げ用文章では、主要な英語名などをカナに置き換えている。名称中の答えを伏せる問題は冒頭を「___には答えが入ります。」とし、読み上げでは「ほにゃらら」とする。

文字コードはUTF-8、BOM付き。固定IDは `memes-20261108-001` から `memes-20261108-300`。同じCSVを再取り込みすると同一IDの問題が更新される。

アプリのCSV解析・共有スキーマで300問、ID・問題文・正解の重複なし、全列の書き出しと再解析の一致を確認。既存900問と合わせた1200問のID照合と、新規300問の再取り込み時に追加重複が生じないことも確認済み。
