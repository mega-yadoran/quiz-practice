# 3ジャンルの問題集CSV

2026年11月8日作成・改稿。各300問、合計900問。

abc本戦800問の関連分野を確認し、各ジャンル200問、計600問を題材から差し替えた。主要人物や基本定義だけに偏らないよう、周辺人物・制作背景・作品横断の知識、故事・言語学、ネット発の作品や文化などへ範囲を広げている。手がかりを段階的に示す問題と、短く直接問う問題を混ぜた。

| --- | --- |
| アニメ・漫画・ゲーム 300問 | [anime-manga-games-300.csv](anime-manga-games-300.csv) |

| 3ジャンルの一括取り込み用 900問 | [all-genres-900.csv](all-genres-900.csv) |

アプリの「問題を管理」→「CSV取り込み」で選択する。問題集名と大・小ジャンルはCSVに設定済み。一括版でも、ジャンル別の3つの問題集に分かれる。

各問に正解、必要な別解、出典URL、短い解説、出典確認日を収録。漢字の読みを問う50問には、答えを先に読み上げないよう文字の構成などを説明する読み上げ用文章を設定した。

名称の中の答えを伏せる問題は、冒頭を「___には答えが入ります。」とし、該当箇所を `___` で表示する。読み上げでは「ほにゃらら」と発声する。

文字コードはUTF-8、BOM付き。ジャンル別版と一括版の問題IDは共通。同じデータを再取り込みすると、同一IDの問題が更新される。

改稿前の900個の問題IDと問題集名を保持している。今回の更新は601問の問題文と600問の正解に及ぶ。一括版の再取り込みで全900問を更新できる。旧版とのID照合で、更新900問・追加0問となることを確認済み。

アプリのCSV解析・共有スキーマで、各300問・合計900問、IDと問題文の重複なし、全列の書き出しと再解析の一致を確認済み。
