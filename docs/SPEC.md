# 初版の確定仕様

2026-11-07にプロトタイプ完成。ユーザーから動作確認済みの報告あり。以下の「次の候補」は追加実装の確定依頼ではない。

- 利用者1名。所有者メールアドレス `yado@mega-yadoran.jp`。
- iPhone 13 mini / iOS 27.0.1のSafari、およびPCのChrome。オンラインで利用。
- React + Vite + TypeScript、Hono、Cloudflare Workers、D1、Access。
- 現在の公開先は https://q-practice.yado-quiz.workers.dev 。希望の `q-practice.mega-yadoran.jp` は対象アカウントに親ドメインのゾーンがないため保留。
- 短い単語・語句で回答する問題。選択式・長文の意味判定は対象外。
- 出題範囲は全問題のみ。お気に入り・分野での出題絞り込みは今後の拡張。
- 一巡内で重複なし。解答中の問題と進み具合をD1に保存し、端末を変えても再開可能。
- 読み上げはボタン操作で開始し、「解答する」で停止。最後まで読んだ場合も回答可能。
- 次の問題を取得後、読み上げ開始ボタンを押す。iPhoneの音声再生をユーザーのタップから確実に開始するため、ページを開いた際の自動読み上げは行わない。
- 原則、問題文は判定後に全文表示。設定で常時表示、または「文字を見て回答」も可能。
- 音声読み上げ用の問題文を別に登録できる。
- 判定は正解・登録済み別解と照合。前後空白、全角半角、英字の大文字小文字を正規化。
- 判定後に正解扱いへ変更可能。スキップは正解率の集計対象外。
- 判定後の星ボタンと問題一覧からお気に入り追加・解除。お気に入り一覧で確認可能。
- 手入力で追加・編集、UTF-8 CSVで最大500問ずつ取り込み。プレビューと同一ID更新を用意。
- 問題IDは固定。CSV再取り込み時にお気に入りと過去の履歴を保持。
- 問題数・今日の解答数・累計正解率、日時・回答・判定の履歴。
- 読み上げ速度と問題文表示の設定はD1に保存。
- 初版の音声回答はiPhone標準キーボードの音声入力。専用録音・認識は後から追加。
- 問題CSV、全データJSONの書き出し。完全復元用SQLバックアップはREADMEの手順で作成。

## 公開時の保護

Cloudflare Accessのメール許可リストとWorkerでのJWT検証を併用。認証設定未完了の場合は閉じる。画面・API・静的ファイルを認証し、別サイトからの更新要求を拒否する。開発用の認証省略は、local環境かつloopbackホストの場合だけ許可する。
