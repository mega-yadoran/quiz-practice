# 初版の確定仕様

2026-11-07にプロトタイプ完成。ユーザーから動作確認済みの報告あり。以下の「次の候補」は追加実装の確定依頼ではない。

- 利用者1名。所有者メールアドレス `yado@mega-yadoran.jp`。
- iPhone 13 mini / iOS 27.0.1のSafari、およびPCのChrome。オンラインで利用。
- React + Vite + TypeScript、Hono、Cloudflare Workers、D1、Access。
- 現在の公開先は https://q-practice.yado-quiz.workers.dev 。希望の `q-practice.mega-yadoran.jp` は対象アカウントに親ドメインのゾーンがないため保留。
- 短い単語・語句で回答する問題。選択式・長文の意味判定は対象外。
- 出題範囲は全問題のみ。お気に入り・分野での出題絞り込みは今後の拡張。
- 一巡内で重複なし。解答中の問題と進み具合をD1に保存し、端末を変えても再開可能。
- 読み上げは出題に合わせて自動開始。「解答する」を押すと回答欄へ切り替え、0.3秒後に再生を停止する。最後まで読んだ場合も回答可能。
- 「次の問題へ」で音声の読み込み・読み上げを自動開始。初回表示・再開時も再生を試み、自動再生が拒否された場合のみ再生ボタンを表示。
- 原則、問題文は判定後に全文表示。設定で常時表示、または「文字を見て回答」も可能。
- 音声読み上げ用の問題文を別に登録できる。
- 判定は正解・登録済み別解と照合。前後空白、全角半角、英字の大文字小文字を正規化。
- 判定後に正解扱いへ変更可能。スキップは正解率の集計対象外。
- 正解判定が確定した直後と、手動で正解扱いに変更した直後に、添付の正解音を通常速度で1回再生する。不正解・スキップ・ページ再読込では再生しない。端末が再生を拒否した場合は結果を表示し、正解音の再生ボタンを案内する。
- 判定後の星ボタンと問題一覧からお気に入り追加・解除。お気に入り一覧で確認可能。
- 手入力で追加・編集、UTF-8 CSVで最大10,000問のファイルを選択し、200問ずつ取り込み。プレビューと同一ID更新を用意。
- 問題IDは固定。CSV再取り込み時にお気に入りと過去の履歴を保持。
- 問題数・今日の解答数・累計正解率、日時・回答・判定の履歴。
- 読み上げ速度と問題文表示の設定はD1に保存。
- 初版の音声回答はiPhone標準キーボードの音声入力。専用録音・認識は後から追加。
- 問題CSV、全データJSONの書き出し。完全復元用SQLバックアップはREADMEの手順で作成。

## 公開時の保護

Cloudflare Accessのメール許可リストとWorkerでのJWT検証を併用。認証設定未完了の場合は閉じる。画面・API・静的ファイルを認証し、別サイトからの更新要求を拒否する。開発用の認証省略は、local環境かつloopbackホストの場合だけ許可する。

## ローカルでのGoogle音声追加（2026-11-07）

- ローカルでGoogle Standardの日本語男性音声 `ja-JP-Standard-D` を使用（Chirp 3 HDから変更、ユーザーによるChirp音声の再生確認済み）。秘密設定のAPIキーを使い、声は設定ファイルで変更可能。
- 未回答の問題を表示すると音声を自動準備・再生し、通常の開始ボタンは表示しない。失敗時のみ準備の再試行・再生ボタンを表示。途中停止・読み直し・速度設定・読み上げ用文章を維持。
- 準備した音声は同じ出題画面の間だけ再利用。Googleの生成に失敗した場合は理由を案内し、文字での回答も可能。
- 読み上げ中の「解答する」は、赤い丸形・台座・押下時の沈み込みがある早押しボタン。停止すると回答欄へフォーカスする。
- 音声準備後は、保存済みの「問題」の音声を通常速度で再生し、終了後0.3秒あけて問題本文を設定速度で読む。読み直しも同じ順。告知中・待機中の停止や画面移動で本文の再生も取り消す。
- 問題本文・読み上げ用文章の丸括弧（全角・半角、入れ子を含む）とその中身は読み上げから除去する。画面・保存データ・CSVは変更しない。閉じ括弧の欠落時は残りを除去し、読み上げ文が空になる場合は案内する。
- 本番もGoogle音声の設定を用意。公開前にAPIキーをWorkerのシークレットへ登録し、公開後にiPhone実機で確認する。

## 問題集・ジャンル・再回答の追加（2026-11-07）

- 問題集を独立した管理単位として作成。問題管理・お気に入りで問題集を絞り込める。既存の問題は未分類として保持。
- 問題は問題集、大ジャンル、小ジャンル、正解扱いの別解、△扱いの再回答候補を保持。手入力・CSV・書き出しに対応。
- 添付の番号付きCSV形式は、問題集名と番号で固定IDを作成。○・通常の別表記を別解、△を再回答候補へ分離し、×のデータは登録しない。
- △に一致する回答は「もう一回」と案内し、正誤・履歴・成績を確定せず、同じ出題に再回答できる。再読み込み後も継続可能。
- 出題時の問題集・ジャンル・再回答候補をスナップショット保存。出題後の編集は判定へ反映しない。
- 練習は全問題から出題。問題集による出題範囲の指定は別の拡張。

## 問題集管理の追加（2026-11-08）

- 「問題を管理」から問題集管理画面を開き、問題集ごとの件数・作成・名前変更・CSV保存・削除を操作できる。
- 名前変更は空白・100文字超・既存名との重複を拒否。所属問題のIDとお気に入りを維持し、履歴・出題スナップショットは書き換えない。
- 削除は問題数・影響を表示し、問題集名の入力で確定。問題集と所属問題を一覧・出題から外し、お気に入りを解除。未回答の出題は中止して集計から除外し、回答済みの履歴・成績は保持する。
- 削除前に問題集ごとのCSVを保存でき、同じIDの再取り込みで問題を戻せる。全データJSONは削除済み問題と中止した出題も保管する。
- 未分類は固定の区分として扱い、名前変更・一括削除は対象外。
